# Comparativa de marcos de seguridad

## Descripción

En este repositorio se presenta un trabajo realizado sobre diferentes marcos y metodologías relacionados con gobierno, arquitectura y seguridad de TI.

El trabajo compara COBIT, TOGAF, SABSA y NIST Cybersecurity Framework, y explica cómo pueden coexistir dentro de un contexto de seguridad.

## Objetivo

El objetivo de la actividad fue identificar las características principales de cada marco y analizar la forma en que pueden complementarse dentro de una organización.

## Marcos incluidos

- **COBIT:** gobierno y gestión de TI.
- **TOGAF:** arquitectura empresarial.
- **SABSA:** arquitectura de seguridad basada en riesgos.
- **NIST Cybersecurity Framework:** gestión del riesgo de ciberseguridad.

## Contenido del trabajo

El documento incluye:

1. Descripción de los cuatro marcos.
2. Comparativa de su coexistencia dentro de un contexto de seguridad.
3. Un flujo de integración entre SABSA, COBIT, TOGAF y NIST CSF.
4. Un caso de uso aplicado a una organización financiera.
5. Referencias bibliográficas.

## Aprendizaje

La realización de este trabajo permitió identificar que los marcos de seguridad y arquitectura no necesariamente tienen que utilizarse de forma aislada. Dependiendo de la necesidad de una organización, pueden complementarse para relacionar los objetivos del negocio con la gobernanza, la arquitectura y la operación de seguridad.
