# Comparativa de marcos de seguridad

## Descripción

En este repositorio se presenta una comparativa entre diferentes marcos y metodologías utilizados en el ámbito de la tecnología y la seguridad de la información.

El trabajo analiza principalmente COBIT, TOGAF, SABSA y NIST Cybersecurity Framework, considerando su enfoque y la forma en que pueden utilizarse dentro de una organización.

## Objetivo

El objetivo de este trabajo fue identificar las características principales de cada marco y comparar su utilidad dentro de un contexto relacionado con la seguridad y la arquitectura de TI.

## Marcos analizados

- COBIT
- TOGAF
- SABSA
- NIST Cybersecurity Framework

## Contenido

En este repositorio se incluyen los materiales correspondientes al trabajo realizado, así como la comparación de los diferentes marcos y su aplicación en un contexto de seguridad.

## Aprendizaje

La realización de esta actividad permitió identificar que cada marco tiene un enfoque diferente y que pueden utilizarse de manera complementaria dependiendo de las necesidades de una organización.
